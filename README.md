# Frame - CS185 W26 Project

Frame is a research-driven UI/UX project focused on seamless, event-based photo sharing across iOS and Android.

## Overview

Instead of manually sorting photos, creating albums, and sharing links across apps, Frame proposes:

- Automatic event detection
- Intelligent photo grouping
- Smart, secure sharing
- Transparent AI-assisted workflows

This website documents the full project journey from GR1 through GR10.
